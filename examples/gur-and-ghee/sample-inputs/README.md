# Sample Inputs, Gur & Ghee

Raw exports of the kind a founder downloads from a store admin and an ads account. Invented, like everything else in this folder.

| File | What it is |
|---|---|
| `shopify-orders-28d.csv` | Daily orders by channel, 16 May to 12 June 2026. Channels: D2C, Zomato-Swiggy, Blinkit, Corporate |
| `shopify-products.csv` | The nine products with price, stock, units sold, conversion rate and rating |
| `meta-ads-spend.csv` | Daily Meta spend by campaign. `khajur-tiffin` starts on 1 June |
| `google-ads-spend.csv` | Daily Google search spend, one campaign |
| `reviews-export.csv` | The 32 messages in `brand-brain/reviews.md`, as a spreadsheet |

The totals in these files reconcile to the growth brief at `my-work/growth-analyst/2026-06-13-brief.md`.

To use one as an input, type `@` in the prompt box and pick the file, or drag it into the chat.
