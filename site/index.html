How this runs

Everything happens in the Claude Code desktop app, the Mac or Windows application. There is no terminal and no command line. You install an app, point it at a folder, and type in a chat box.

Three things you do over and over: type / to see your teammates, watch the progress while a teammate works, and click a file path in the chat to read what it wrote.

Two rules in every session

Index files, not raw outputs

Every teammate writes a short index of what it produced. The Chief of Staff reads only those. That is what lets one agent sit across the whole team.

Default and Power scope

Every teammate asks you to pick. Default fits a Pro plan and the live session. Power is for re-running at home. Pick Default during the live day.

Stuck

  1. Read the "If it breaks" section at the bottom of the session file.
  2. Ask Claude: "Something is wrong. Check what exists in this folder and tell me what is missing."
  3. On Zoom, use Raise hand. A TA will take you into a breakout room.
