Session 00

Setup

15 minutes at home, before bootcamp day. One install and one paste.

You walk out with: the Claude Code desktop app installed, this repo open inside it, and one successful run

Before you start
  • A Claude Pro or Max plan. Claude Code does not run on the free tier. Check at claude.ai under your account.
  • A Mac or a Windows machine you can install software on.
  • About 2 GB of free disk.
The flow
  1. Install the app
  2. Sign in and find the Code tab
  3. Set up the bootcamp folder with one paste
  4. Open the folder, if it asks you to
  5. Meet your teammates
  6. Your first run
  7. Check your permission mode
  8. Fill your brand folder
Check it worked
  • The app is open on the Code tab, running on This computer
  • The setup paste ended with Skills: 11, Agents: 3
  • Typing /brand-brain shows it in the list, marked (project)
  • Your first run answered and you clicked a file path to read something
  • A brand-brain/ folder exists and you have started filling it
What usually goes wrong
  • brand-brain is not in the list.
  • The setup paste failed, or stopped halfway.
  • "Claude Code requires a paid plan".
  • Files keep reverting, or the app says a file changed underneath it.
  • The app is slow or a run stops halfway.

Session 01

Brand Strategist

70 minutes, 9:40 to 10:50 · CLAUDE.md, a persistent project profile

You walk out with: CLAUDE.md at the repo root, filled in your voice, with a voice test scored 4 or better

Before you start
  • Session 0 done, / shows your roster
  • brand-brain/ exists at the repo root, however empty
  • 70 uninterrupted minutes. This is the longest session of the day on purpose. It is the one you cannot rush, because every other teammate reads its output
The flow
  1. Start the session
  2. Answer the persona questions
  3. Watch the demo
  4. Answer the two structure questions
  5. Walk the eight topics
  6. Spend real time on Topic 8
  7. Take the voice test
  8. Save
Check it worked
  • CLAUDE.md exists at the repo root. Click it in the chat to open it in the file pane.
  • Sections 1 to 7 are filled with your real answers, not brackets
  • Section 7 carries an ALWAYS list, a NEVER list, a reading level and your compliance wall
  • The voice test scored 4 or 5
  • Anything you skipped is marked TODO with a note on what is missing
What usually goes wrong
  • It keeps writing marketing filler back at me.
  • It invented a fact about my brand.
  • I ran out of time at topic 5.
  • I want to start over.

Session 09

Growth Analyst

50 minutes, 4:50 to 5:40 · Routines, scheduled runs inside the desktop app

You walk out with: your first weekly brief, a dashboard that opens on a double click, and a routine that produces it again every Monday without you asking

Before you start
  • brand-brain/unit-economics.md filled with your real numbers, however rough
  • Your last 30 to 90 days of orders exported from your store as a CSV file and saved in brand-brain/. If you do not have it, use the sample file examples/little-lab/sample-inputs/shopify-orders-28d.csv
  • Ad spend for the same period, as an export or a screenshot, if you run ads
  • Customer Researcher and competitor reports in my-work/
The flow
  1. Run the brief
  2. Open the dashboard
  3. Read the alarm, and only the alarm
  4. Check what it says is estimated
  5. Do the action
  6. Schedule it
  7. Know the limits of a local routine
  8. Test it before you trust it
  9. Save what you set up (at home)
Check it worked
  • my-work/growth-analyst/ has a brief, an index, data/numbers.json and dashboard.html
  • The dashboard opens on a double click, with no server
  • You can state the one alarm in a sentence
  • The action is done or in your calendar
  • A routine exists, and you watched it fire once
  • schedule-config.md records what you set up
What usually goes wrong
  • Every number says "no data".
  • The brief and my own numbers disagree.
  • It refused to compute CAC.
  • The routine did not fire.
  • The routine fired but sent me four pages.
